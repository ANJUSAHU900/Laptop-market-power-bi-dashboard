## 📌 Project Overview
This project provides an end-to-end exploratory analysis of the laptop consumer market. The dashboard offers key market intelligence by correlating pricing structures with technical specifications such as RAM capacity, processor brands, and manufacturer discounts.

---

## 🔑 Key Insights & Analytics
- **Brand Volume & Distribution:** Analyzed product availability and market share across leading laptop brands.
- **Pricing Dynamics:** Tracked and compared average and latest retail price points by brand and specific model tiers.
- **Hardware vs Price Analysis:** Evaluated how RAM size (GB) and processor brand choices directly influence market pricing.
- **Discount Patterns:** Analyzed retail discount percentages across manufacturers to identify aggressive pricing strategies.
- **Interactive Slicing:** Multi-variable filters for brand, processor type, and memory configurations for custom exploration.
